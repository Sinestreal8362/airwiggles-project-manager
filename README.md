## Overview

Airwiggles turns project planning into a structured web workspace where work can be divided into projects and tasks. Teams can keep related information together, coordinate responsibilities, and monitor progress through a browser-based interface.

The application is suitable for both personal organization and shared team workflows. Users may access it through a hosted deployment or serve it locally, depending on how they prefer to manage their project workspace.

---

## Core Capabilities

- Maintain and organize multiple projects
- Create, order, and manage tasks within projects
- Work together with team members
- Track activity and progress across current projects
- Manage project work from a browser
- Keep project details in a shared workspace
- Deploy the application locally for self-managed access
- Use a hosted deployment when available

## Using Airwiggles

1. Launch Airwiggles in your web browser.
2. Set up a project for the work you need to manage.
3. Add tasks and arrange them to match your process.
4. Provide the appropriate project information to team members.
5. Check task activity and project status as work progresses.
6. Continue with either the hosted workspace or your local installation.

When testing locally, start the web server configured for your environment and open its local address in a browser.

## Frequently Asked Questions

### What type of users can use Airwiggles?

Airwiggles is built for individuals and teams who want a shared workspace for project planning, task management, and ongoing coordination.

### Does the application support local use?

Yes. Run the application files through a local web server, then open the server's assigned address in a browser.

### Can I use a hosted deployment?

Yes, when a hosted deployment is available. The download link above leads to the designated project page.

### What is a good way to organize project information?

Use separate projects for different areas of work, and manage the related tasks and progress inside each project's workspace.

### What can I check if Airwiggles will not open?

Make sure the files were downloaded or cloned successfully, confirm that a web server is serving them, and verify that you are using the correct hosted or local address.

### Where do updates come from?

Updates are made available through the project repository and its published builds. Review the repository for the latest version and deployment details.
